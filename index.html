📘 Materi Persamaan Kuadrat

Pada halaman ini, kamu akan mempelajari pengertian, bentuk umum, pemfaktoran, dan rumus ABC.

1. Pengertian Persamaan Kuadrat

Persamaan kuadrat adalah persamaan matematika yang memiliki pangkat tertinggi variabel berupa dua.

Contoh:

x² + 5x + 6 = 0

2. Bentuk Umum Persamaan Kuadrat

ax² + bx + c = 0

Keterangan:

  • a = koefisien x², dengan a ≠ 0
  • b = koefisien x
  • c = konstanta
  • x = variabel

Contoh: x² + 5x + 6 = 0

  • a = 1
  • b = 5
  • c = 6

3. Menyelesaikan dengan Pemfaktoran

Pemfaktoran dilakukan dengan mencari dua bilangan yang hasil kalinya sama dengan c dan jumlahnya sama dengan b (untuk a = 1).

Contoh Soal

Tentukan penyelesaian dari:

x² + 5x + 6 = 0

Langkah 1: Tentukan dua bilangan

Kita mencari dua bilangan yang:

  • Hasil kalinya 6
  • Jumlahnya 5

Bilangan tersebut adalah 2 dan 3, karena 2 × 3 = 6 dan 2 + 3 = 5.

Langkah 2: Bentuk faktornya

(x + 2)(x + 3) = 0

Langkah 3: Tentukan nilai x

x + 2 = 0, sehingga x = -2

x + 3 = 0, sehingga x = -3

Jawaban

x = -2 atau x = -3

4. Menyelesaikan dengan Rumus ABC

Rumus ABC dapat digunakan untuk menentukan akar-akar persamaan kuadrat.

x = (-b ± √(b² - 4ac)) / 2a

Contoh Soal

Tentukan akar-akar dari:

x² - 5x + 6 = 0

Langkah 1: Tentukan nilai a, b, dan c

  • a = 1
  • b = -5
  • c = 6

Langkah 2: Masukkan ke rumus ABC

x = (-(-5) ± √((-5)² - 4(1)(6))) / 2(1)

Langkah 3: Sederhanakan

x = (5 ± √(25 - 24)) / 2

x = (5 ± 1) / 2

Langkah 4: Tentukan kedua akar

x₁ = (5 + 1) / 2 = 3

x₂ = (5 - 1) / 2 = 2

Jadi, akar-akarnya adalah x = 3 dan x = 2.

5. Kesimpulan

Persamaan kuadrat dapat diselesaikan menggunakan beberapa cara, di antaranya pemfaktoran dan rumus ABC.

📚 Literasi Matematika

Selamat datang di latihan Literasi Matematika! Kerjakan empat soal berikut dengan membaca informasi, melakukan perhitungan, dan menuliskan kesimpulan.

Soal 1 – Mathematical Reasoning

Memilih Ukuran Taman

Sebuah taman berbentuk persegi panjang memiliki luas 84 m². Panjang taman 5 meter lebih besar daripada lebarnya. Berdasarkan informasi tersebut, tentukan pasangan panjang dan lebar taman yang tepat.

  • A. Panjang 12 m dan lebar 7 m
  • B. Panjang 14 m dan lebar 6 m
  • C. Panjang 10,5 m dan lebar 8 m

Soal 2 – Formulating Situations Mathematically

Menentukan Ukuran Tempat Parkir

Sebuah tempat parkir berbentuk persegi panjang memiliki luas 180 m². Panjang tempat parkir tersebut 3 meter lebih besar daripada lebarnya.

Buatlah model matematika dari situasi tersebut, kemudian tentukan ukuran panjang dan lebarnya.

Soal 3 – Employing Mathematical Concepts, Facts, and Procedures

Menentukan Waktu Bola

Ketinggian sebuah bola yang dilempar ke atas dinyatakan dengan fungsi h(t) = -5t² + 20t + 25, dengan h(t) dalam meter dan t dalam detik.

Pada saat tertentu, bola berada pada ketinggian 40 meter. Tentukan waktu ketika bola berada pada ketinggian tersebut.

Soal 4 – Interpreting, Applying, and Evaluating Mathematical Outcomes

Menafsirkan Hasil Ukuran Kolam

Sebuah kolam renang berbentuk persegi panjang memiliki luas 96 m². Panjang kolam 4 meter lebih besar daripada lebarnya.

Dari penyelesaian persamaan kuadrat diperoleh dua nilai untuk lebar, yaitu 8 dan -12.

Jelaskan nilai yang dapat digunakan dalam konteks ukuran kolam, kemudian tentukan panjang kolam dan periksa kebenaran hasilnya.
